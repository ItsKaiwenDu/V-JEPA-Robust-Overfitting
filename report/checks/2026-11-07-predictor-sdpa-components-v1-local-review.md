## Refusal and preservation

Tests cover changed/rehashed actual values and metadata, missing or failed prior
workers, changed canonical references, source/domain/runtime/layout drift,
nonfresh PIDs, reset attempts, partials, symlinks, hardlinks, unsafe modes,
oversized files and NPY header/allocation/pickle hazards. Readers recompute the
saved numerical checks; passing booleans cannot promote bad actual values.

Numerical refusal preserves untimed returns and stops before profiling. A profile
value mismatch or unrecognized backend preserves profiled arrays and actual event
rows. Nonfinite FP64 values are saved and rejected. Interrupted publication keeps
partial bytes and the primary exception even when final publication also fails.

The CUDA recognizer is parser-tested with explicitly synthetic rows. It requires
device-zero events associated with actual operators in both phases, recognized
efficient or math kernel families, and math matrix/softmax evidence. Flags,
unassociated events, the wrong device/phase, mixed or unsupported families refuse.
There is no silent fallback or assumption that the default is efficient. No CUDA
kernel family has been observed in this milestone.
