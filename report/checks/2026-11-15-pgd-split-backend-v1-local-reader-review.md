# Native-forward/math-backward metadata reader verified

The new local reader assesses the native and forward-preserving representative
backend recipes without importing scientific packages or running a profiler.
Native forward/backward association and custom outer/inner math association are
explicitly separate. Source thread plus sequence, unique producer ancestry and
a direct matching engine/node parent are required even when backward runs on
another thread. Every relevant matrix/softmax operator needs a positive actual
recorded GPU link to a qualified frontend CPU host. Names/durations alone cannot
supply identity; individual GPU correlation IDs need not be globally unique.

The exact frozen raw projection preserves overhead signatures, GPU annotations,
linked runtime records and original indices. No raw rows are removed, rewritten
or repaired. Overhead and annotations cannot supply kernel witnesses. Existing
same-family validators and historical refusals remain unchanged; the synthetic
hybrid still refuses under that older policy.

The reader enforces 4 MiB / 20,000 raw events, 128-deep ancestry, 16 producer
anchors and a 128 KiB assessment. Its private file loader requires the exact
`events.json` name, expected digest, 0700 parent and 0600 single-link owned file;
held source/parent identity, mode, extent and nanosecond-mtime changes refuse.
The local CLI preserves a bounded private assessment or explicit refusal in a
fresh directory. It starts no worker, profiler or connection.

**Validation:** 123 distinct new checks pass with zero errors/failures/skips:
114 initial synthetic checks plus nine additional source-race and owner-link
regressions. No passing check was repeated. Reader/CLI source stayed unchanged
after initial testing. The isolated CLI blocks scientific imports, child process
launches and network calls inside the auditor. No model, tensor, gradient, SDPA,
actual profiler, GPU, SSH, proof, retrieval, cleanup or paid work ran.

Independent standard-library saved-file review verifies all test records, source
snapshots, the unchanged initial test bodies, four synthetic producer anchors and
seven exact GPU/CPU launch links. It preserves 4,535 prior hashes and historical
242/280/135/245/5/3 descriptor groups including byte/mode/nanosecond-mtime checks.
Both previous claims remain consumed; old worker results and numerical rejections
are unchanged.

The assessment is metadata only. Control/boundary bindings are syntax/context
checks, not authenticated lineage. It admits no geometry/accuracy, actual native
root/leaf/GraphTask ownership, CUDA execution, worker completion, full EOT8 backend
coverage, replay, speed/cost or training. Expected custom-function trace names
have synthetic/source-supported coverage here, not a new target observation.
