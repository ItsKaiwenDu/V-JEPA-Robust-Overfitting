scope, raw CUDA records and CPU-linked kernels. The reader matches backward
nodes to the owned forward call using sequence/thread association, refuses
missing/ambiguous links and checks both mask-family calls for each owner.
Predictor math requires actual math forward and matrix/softmax backward evidence;
reference and encoder require actual efficient forward/backward evidence. GPU
annotation copies are excluded from raw-kernel proof. No conserved timing

not establish the target GPU's behavior. **CUDA proof covers the profiled first
