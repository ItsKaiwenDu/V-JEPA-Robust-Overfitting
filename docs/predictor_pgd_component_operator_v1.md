## Concrete interfaces

The bootstrap requires a new component control and one exact scoped authorization.
It checks the child plan, parent/session digest, source hashes, ownership, role
prefix and continuing deadlines before installing the 43-source private cache.
Project imports have no ambient fallback: models and attacks must resolve through
that cache, with exact source, parent package, loader, origin and search path.
Reload and changed bytes refuse. The existing worker entry is still null in its
source; only the authenticated child dispatch supplies the separate control,
host and disjoint capsule/result binding immediately before its component call.

The saved repaired OS launcher creates an isolated child session and anonymous
release pipe. It verifies the child identity, binds an owned PID handle and runs
the storage/GPU guards before writing the single release byte. Failure closes the
pipe and cleans up only held owned handles. The existing observed-process and RSS
monitor, non-reaping process assumptions, continuing clocks and cleanup remain.
Parent verification requires the real full storage-proof receipt or the exact
source-bound component completion, backend, progress and parent/resource records.
No failed metadata is promoted into scientific or training admission.

The hard/soft alarm implementation, causal client deadline mapping, same-SSH
framing, private publication, priority/deduplicated transfer, journal and terminal
validation are inherited. Whole-module AST inverses verify the adapters. The new
source catalogue accounts for 83 assets after installation and 30 component/
collection result paths. The proof log is `proof.log` in the supervisor root. It
is intentionally outside capture: the unchanged component writer rejects a proof
log in its output namespace. Failure diagnostics name the correct path.

All original resource limits remain: setup/proof 3 GiB, capture 2.25 GiB, response
3 GiB, raw 1,792 MiB, metadata 64 MiB including trace 8 MiB, allocator 7 GiB and

minutes including login. The work origin never resets. No retries, new retrieval
