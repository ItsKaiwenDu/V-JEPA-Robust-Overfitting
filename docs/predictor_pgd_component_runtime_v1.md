The verified input capsule is now connected to a separately named, component-only
worker source path and the corrected backend v3 reader. The emitted source graph
contains 37 files / 412,198 bytes, including seven new modules. The old numerical
entry, eight-objective worker and full-cohort dispatcher are absent. Preparing and

The generated entry contains `EXECUTION_BINDING=None` and refuses before source or
runtime ports when unbound. This is local source integration, not a runnable
university handoff. The immutable generated bytes and their manifest are under
`runs/pretrained/diagnostic/pgd-component-runtime-v1-20261119/cold-source-v3/`
and `SOURCE-MANIFEST-v3.json`.

## Historical inputs and fresh results

The source adapter checks the capsule's closed private directory tree, all 35
member hashes and the exact manifest and contract. Its original source control,
boundary and accepted numerical provenance stay fixed. Loaded metadata and file
identities are checked again before operands and during restoration. It never
writes to the capsule.

A future execution must have a distinct control and a disjoint result directory.
The entry accepts only a component role, source/result roots, control and continuing
deadline. It has no numerical-source arguments or numerical dispatch branch. One
claim is consumed per fresh namespace, with no retry or reset. The original
numerical result and failed native worker are never renamed or promoted.

The component's source receipt explicitly carries both historical source and new
execution controls, plus capsule contract/manifest and boundary identities. The
worker and completion reader require the exact receipt. Worker/completion kinds
are separately named. The result inventory admits only the two component result
prefixes and their two logs: 28 fixed paths. Full numerical and source-boundary
publication paths refuse. The original byte writer, publication ordering and
resource/category ceilings remain unchanged.

## Integration issues resolved locally

JSON represents backing-group map keys as strings. The original Python layout gate
expects integer group IDs. A bounded descriptor conversion restores IDs 0–7 for
that map only; raw manifest bytes, shapes, strides, offsets, alias groups and values
remain unchanged. The original strict layout comparison is retained.

An import-only dependency walk also missed projection v2, which backend v3 reads
as a pinned sibling file without importing it. The source graph now includes all
five backend file pins as explicit data dependencies. A cache-local source-gate
check passes on the emitted files and refuses a changed projection-v2 file.
