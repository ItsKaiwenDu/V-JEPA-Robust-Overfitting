# Local component session core

The component-only worker graph now has a local session core for whole-scratch
accounting, private source-cache verification, owned process supervision and
priority collection. The core was exercised with ordinary local files and explicit
simulation ports. It does not yet have an OS launcher, live bootstrap, SSH client
or hard blocking-I/O alarm binding. `LIVE_EXECUTION_BINDING=None`, `live_run()`
and `install_live()` refuse live execution.

This step reuses the accepted eight-gradient / four-pair numerical result. It
neither reruns that cohort nor changes the historical failed native component.
No university scope, handoff, approval request or live attempt is prepared.

## Fixed inputs and scratch accounting

The input contract pins 83 existing files. The session catalogue has 77 immutable
assets, 37 cache modules and 31 fixed component/collection result or log paths.
The accepted capsule and worker graph stay byte-identical. Historical source
control remains separate from the unbound future execution identity. Numerical

Only catalogue construction and path classification are specialized. The original
raw/metadata publication transitions, ownership, mode, link, inode, category,

first run had 18 passes, five failures and eight fixture setup errors because the
test helper left intermediate directories at mode 0755. The corrected helper
creates every directory at 0700. Only those 13 failed/setup-error cases were rerun,
and all passed. Production source stayed identical across both test runs. All
old/new test snapshots, failures, fixtures and logs are retained; no passing,
historical or scientific case was repeated.

reserve byte fixture. They simulate capacity/inode observations, processes,

unchanged real proof verifier rejects it. There is no 2.5 GiB allocation proof,

No real resource, scientific or ownership qualification follows.

The standalone stdlib saved/hash/AST/wire audit passes: 21,716 prior hashes and
22,683 prior fixture entries are intact. The old FIFO is inspected with `lstat`
only and never opened. The review invokes no project/test callbacks or scientific,
process, signal, timer or network work. It verifies all source pins, catalogue,
codec inverse, test history, fake receipts, independent wire reconstruction and
