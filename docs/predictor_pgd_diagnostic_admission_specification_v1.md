## Refusal and evidence semantics

The16 refusal rows cover absent review/authority, consumed or ambiguous history,
source/control mismatch, malformed domain, invalid clocks, unknown quiescence,
unconfirmed ownership, serial role/release mismatch, unowned failures, moved
guards/durability, changed science/caps, missing receipts, collection mismatch,
unjoined provenance and actions outside scope. Every row retains already
occurred effects, primary errors and consumed claims, and authorizes no new
dependent work or retry. Unknown ownership never permits collection or clock
handoff. A closed descriptor alone is not confirmed death.

Eight state descriptions distinguish DRAFT_ONLY, SOURCE_REVIEW_PENDING,
FRESH_AUTHORITY_PENDING, ATTEMPT_CONSUMED, OWNED_WORK_OBSERVED,
HELD_UNCONFIRMED, REFUSED_OR_INCOMPLETE and IDLE_EVIDENCE_PENDING_REVIEW.
Only DRAFT_ONLY describes this new preparation. They are not an implemented
state machine. Every state keeps actual execution/research/training admission
false. An idle/complete documentary outcome still requires independent evidence
review and every later qualification gate.

The12 independent review obligations each join exactly two requirements to
their inherited source anchors and unchanged missing-evidence statement.
Documentary coverage is not implementation, an inverse/domain proof, physical
ownership/process/clock/cap enforcement, deployed build attestation or a
security boundary. No new test membership/oracles are planned or run here.
The old32-case pass/41 logical calls and43 source anchors are inherited,
not repeated, broadened or silently treated as proof of these new requirements.
