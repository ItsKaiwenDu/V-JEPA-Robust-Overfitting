## What the harness checks

The module has no filesystem, process, timer, network or tensor-library port.
It interprets inert programs representing capture submission/completion,
exporter retention, consumption, cleanup and receipt eligibility. Supplied
ownership, writer, generation, stream and clock labels are compared as metadata;
they are never authenticated physical facts. Clock labels are provided integers,
not observed time. No stopwatch is used.

Fourteen planned port responsibilities are represented in the supplied state.
Two representative call labels cover the separate tensor-hash and ordered-name
state-stream recipes. The27 original mapped call sites are not executed, and
the harness does not prove their reachability or actual operator semantics.

| Area | New symbolic checks |

| Capture and ordering | Unknown writers, shared capture, missing alias graph, writer changes, pending or mismatched completion, and unrelated writer ordering |
| Containment and consumption | Escaping exporter, changed owner, reentrant consumer label, partial read failure, premature release and receipt before completion/cleanup |
| Bytes | Independent literal golden streams for flat opaque bytes and ordered name/chunk pairs; reject changed offset/extent/padding, numeric-conversion labels, reordered names and inserted separators |
| Failure | Cancellation before allocation/during export, interruption with pending use, held resources, confirmed quiescence and primary-error preservation through cleanup errors |
| Boundaries and resources | Repeated fresh generations, reused generations/double consumption/release, moved observation boundary, supplied deadline exhaustion/regression/domain change, distinct live allocation accounting and forbidden-effect requests |
| Unqualified cases | Unsupported/unknown domain and shape labels remain unproven; every physical/refusal/admission flag stays false |

P19 consumes only the first two opaque bytes before an injected consumer failure;

P26 reaches two fresh observation generations with unchanged object/version
